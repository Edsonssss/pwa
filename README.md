# Задачи — PWA для iOS

Офлайн-PWA «список дел» в стиле нативного iOS. Чистый HTML + CSS + JS: **без сборки, без фреймворков, без зависимостей** в рантайме. Раскладывается на любой статический хостинг с HTTPS и ставится на iPhone как обычное приложение.

## Что умеет

- **iOS-внешность**: large title со схлопыванием в навбар, grouped-списки, segmented-контрол, bottom sheet с «ручкой», системные цвета и тёмная тема, safe-area под «чёлку» и home-индикатор.
- **Задачи**: создание/редактирование в шторке, срок (нативный date-picker), приоритет, заметка, поиск, вкладки «Все / Сегодня / Готово».
- **Жесты**: свайп строки влево — удаление (как в Mail), свайп вниз за ручку — закрыть шторку, toast с «Вернуть».
- **Офлайн**: service worker кэширует оболочку (stale-while-revalidate + network-first для навигации), задачи лежат в `localStorage`. Индикатор «офлайн» в шапке.
- **Установка**: manifest + иконки (180/192/512 + maskable), ярлык «Новая задача» (`?new=1`), подсказка «Поделиться → На экран “Домой”» для Safari и нативный prompt в Chrome/Android.
- Счётчик активных задач в `document.title`, стаггер-анимации, `prefers-reduced-motion`.

## Структура

```
pwa-tasks/
├── index.html            разметка + iOS-мета-теги
├── styles.css            дизайн-токены iOS, light/dark, safe-area
├── app.js                состояние, рендер, жесты, шторка, установка
├── sw.js                 service worker (офлайн-оболочка)
├── manifest.webmanifest  имя, иконки, display: standalone, shortcuts
├── serve.js              мини-сервер для предпросмотра (0.0.0.0)
├── icons/                apple-touch-icon 180, 192/512, maskable, favicon, icon.svg
└── tools/
    ├── gen-icons.js      перегенерировать иконки (без зависимостей)
    └── test/smoke.js     smoke-тест логики на jsdom (npm test)
```

## Запуск локально

```bash
node serve.js 8080        # или: npm start
# либо любой статик-сервер:
python3 -m http.server 8080
```

Service worker регистрируется **только по HTTPS или localhost** — для проверки на телефоне нужен HTTPS-хостинг или туннель.

## Установка на iPhone / iPad

1. Задеплойте папку на HTTPS-хост (см. ниже).
2. Откройте ссылку в **Safari** (не во встроенном браузере Telegram/Instagram — там установка недоступна).
3. Кнопка **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран “Домой”»** → «Добавить».
4. Иконка появится на рабочем столе; приложение открывается полноэкранным, без адресной строки Safari.

При первом входе приложение само покажет карточку-подсказку с этими шагами.

## Деплой (HTTPS из коробки)

**Netlify Drop** — самое быстрое: откройте <https://app.netlify.com/drop> и перетащите папку (или архив `pwa-tasks.zip`). Получите `https://….netlify.app`.

**GitHub Pages**
```bash
git init && git add -A && git commit -m "pwa"
git branch -M main && git remote add origin https://github.com/USER/REPO.git
git push -u origin main
# Settings → Pages → Deploy from branch → main / root
```
Все пути в проекте относительные (`./`), поэтому подпапка `/REPO/` работает без правок; SW зарегистрируется с scope подпапки.

**Vercel / Cloudflare Pages** — импорт репозитория, framework: *Other / None*, output directory: корень (`.`).

После деплоя проверьте: DevTools → Application → Manifest (ошибок нет), Service Workers (статус *activated*), Lighthouse → PWA.

## Особенности и ограничения iOS (честно)

- **Push-уведомления**: доступны с iOS 16.4+ и только для установленных на домашний экран PWA, через Web Push (VAPID) + собственный сервер отправки. В этой сборке пушей нет — при желании подключается отдельно.
- **Фоновая синхронизация и бейджи** на иконке в iOS для web недоступны.
- **Хранилище**: WebKit может очистить данные сайта, к которому не обращались ~7 дней (ITP). Для установленного PWA это маловероятно, но критичные данные стоит дублировать (экспорт/бэкап).
- **Splash-экран** при запуске iOS рисует сам по снимку/иконке; отдельные `apple-touch-startup-image` не подключались сознательно (их нужно по размеру на каждую модель).
- Обновление SW происходит при следующем открытии; чтобы форсировать — закрыть все вкладки приложения и открыть заново.

## Кастомизация

- **Имя/цвета установки**: `manifest.webmanifest` (`name`, `short_name`, `theme_color`, `background_color`) и `<meta name="theme-color">` в `index.html`.
- **Иконки**: отредактируйте градиент/галочку в `tools/gen-icons.js` и выполните `npm run icons`.
- **Палитра UI**: блок токенов в начале `styles.css` (`:root` и `@media (prefers-color-scheme: dark)`).
- **Хранилище**: ключ `pwa-tasks:v1` в `app.js`; при желании заменяется на IndexedDB без изменения UI.
