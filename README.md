# Задачи — PWA для iOS

Офлайн-PWA «список дел» в стиле нативного iOS. Чистый HTML + CSS + JS: **без сборки, без фреймворков, без зависимостей** в рантайме. Раскладывается на любой статический хостинг с HTTPS и ставится на iPhone как обычное приложение.

## Что умеет

- **iOS-внешность**: large title со схлопыванием в навбар, grouped-списки, segmented-контрол, bottom sheet с «ручкой», системные цвета и тёмная тема, safe-area под «чёлку» и home-индикатор.
- **Задачи**: создание/редактирование в шторке, срок (нативный date-picker + кнопка «убрать срок»), приоритет, заметка, поиск, вкладки «Все / Сегодня / Готово».
- **Жесты**: свайп строки влево — удаление (как в Mail), свайп вниз за ручку — закрыть шторку, toast с «Вернуть».
- **Офлайн**: service worker кэширует оболочку (stale-while-revalidate + network-first для навигации + офлайн-страница), задачи лежат в `localStorage`. Индикатор «офлайн» в шапке.
- **Установка**: manifest + иконки (180/192/512 + maskable), подсказка «Поделиться → На экран “Домой”» для Safari и нативный prompt в Chrome/Android. Ярлык «Новая задача» (`?new=1`) работает в Chrome/Android: iOS манифестные `shortcuts` не поддерживает.
- **Данные**: экспорт/импорт JSON-резервной копии (через системный share-лист или файл) — страховка от изоляции хранилища iOS и ITP-очистки.
- **Обновления**: новый service worker не рвёт живую сессию — появляется тост «Доступна новая версия → Обновить»; проверка обновлений также при возврате в приложение.
- **Доступность**: шторка как `dialog` с ловушкой фокуса и Escape, галочки как `switch` с `aria-checked`, вежливый анонс счётчика, видимые фокус-кольца, контраст токенов по WCAG AA, зоны касания ≥44 pt.
- Счётчик активных задач в `document.title`, стаггер-анимации, `prefers-reduced-motion`.

## Структура

```
pwa-tasks/
├── index.html            разметка + iOS-мета-теги + полоса под статус-бар
├── styles.css            дизайн-токены iOS (WCAG AA), light/dark, safe-area
├── app.js                состояние, рендер, жесты, шторка, установка, экспорт
├── sw.js                 service worker (офлайн-оболочка + офлайн-страница)
├── manifest.webmanifest  имя, иконки, display: standalone, shortcuts
├── serve.js              мини-сервер для предпросмотра (0.0.0.0, без кэша sw.js)
├── package.json          scripts: start / test / icons
├── icons/                apple-touch-icon 180, 192/512, maskable, favicon,
│                         icon.svg, mask-icon.svg (монохром для закреплённых вкладок)
└── tools/
    ├── gen-icons.js      перегенерировать иконки (без зависимостей, PNG вручную)
    └── test/smoke.mjs    smoke-тест логики на jsdom (npm test)
```

## Запуск локально

```bash
node serve.js 8080        # или: npm start
# либо любой статик-сервер:
python3 -m http.server 8080
```

Service worker регистрируется **только по HTTPS или localhost** — для проверки на телефоне нужен HTTPS-хостинг или туннель.

## Установка на iPhone / iPad

1. Задеплойте папку на HTTPS-хост (см. ниже).
2. Откройте ссылку в **Safari** (не во встроенном браузере Telegram/Instagram — там установка недоступна).
3. Кнопка **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран “Домой”»** → «Добавить».
4. Иконка появится на рабочем столе; приложение открывается полноэкранным, без адресной строки Safari.

При первом входе приложение само покажет карточку-подсказку с этими шагами.

## Деплой (HTTPS из коробки)

**Netlify Drop** — самое быстрое: откройте <https://app.netlify.com/drop> и перетащите папку (или архив `pwa-tasks.zip`). Получите `https://….netlify.app`.

**GitHub Pages**
```bash
git init && git add -A && git commit -m "pwa"
git branch -M main && git remote add origin https://github.com/USER/REPO.git
git push -u origin main
# Settings → Pages → Deploy from branch → main / root
```
Все пути в проекте относительные (`./`), поэтому подпапка `/REPO/` работает без правок; SW зарегистрируется с scope подпапки.

**Vercel / Cloudflare Pages** — импорт репозитория, framework: *Other / None*, output directory: корень (`.`).

После деплоя проверьте: DevTools → Application → Manifest (ошибок нет), Service Workers (статус *activated*), Lighthouse → PWA.

> Для GitHub Pages в репозитории уже лежит `.nojekyll` (иначе Jekyll может вырезать служебные файлы). На Netlify/Cloudflare он безвреден.

## Особенности и ограничения iOS (честно)

- **Статус-бар по версиям iOS**: до 18.x цвет полосы брался из `<meta name="theme-color">`; с iOS 26 этот мета-тег игнорируется, а с iOS 27 игнорируется и `apple-mobile-web-app-status-bar-style`, и установленные PWA рисуют blur поверх верха страницы. Обход, который работает: сплошной `position: fixed` элемент с фоном у самого верха (≥6 px высотой, ≥80% ширины, ≤4 px от верха) — в проекте это `.statusbar-strip`. Мета-теги оставлены как fallback для iOS ≤ 25.
- **Хранилище изолировано от Safari**: при добавлении ярлыка копируются только cookie, `localStorage`/IndexedDB — нет. Поэтому задачи, заведённые в Safari, не появятся в установленном приложении; при первом запуске установленного PWA показывается предупреждение, а кнопки «Экспорт»/«Импорт» делают резервную копию.
- **ITP-очистка**: WebKit может очистить данные сайта, к которому не обращались ~7 дней. Для установленного PWA это маловероятно, но экспорт остаётся рекомендованной практикой.
- **Push-уведомления**: доступны с iOS 16.4+ и только для установленных на домашний экран PWA, через Web Push (VAPID) + собственный сервер отправки. С iOS 18.4 есть Declarative Web Push (`window.pushManager`) без обязательного service worker. В этой сборке пушей нет — при желании подключается отдельно.
- **Фоновая синхронизация и бейджи** на иконке в iOS для web недоступны.
- **Манифестные поля, которые iOS игнорирует**: `shortcuts` (только macOS 17.4+), `background_color`, `display_override`, `purpose: maskable` (на iOS иконку задаёт `<link rel="apple-touch-icon">`). Ярлык «Новая задача» (`?new=1`) поэтому работает в Chrome/Android.
- **Splash-экран** при запуске iOS рисует сам по снимку/иконке; отдельные `apple-touch-startup-image` не подключались сознательно (их нужно по размеру на каждую модель).
- **Обновление SW**: новый worker встаёт в очередь и не перехватывает живую сессию (`skipWaiting` только по явному действию пользователя из тоста). Дополнительно `reg.update()` вызывается при возврате в приложение, а регистрация идёт с `updateViaCache: 'none'`, чтобы HTTP-кэш хостинга не держал старый `sw.js`.
- **С iOS 26** любой сайт, добавленный на экран «Домой», открывается как web app по умолчанию; манифест и иконки при этом используются.

## Кастомизация

- **Имя/цвета установки**: `manifest.webmanifest` (`name`, `short_name`, `theme_color`, `background_color`) и `<meta name="theme-color">` в `index.html`.
- **Иконки**: отредактируйте градиент/галочку в `tools/gen-icons.js` и выполните `npm run icons`.
- **Палитра UI**: блок токенов в начале `styles.css` (`:root` и `@media (prefers-color-scheme: dark)`).
- **Хранилище**: ключ `pwa-tasks:v1` в `app.js`; при желании заменяется на IndexedDB без изменения UI.
