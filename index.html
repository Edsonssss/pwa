Пока пусто

Приложение установлено офлайн: задачи хранятся на устройстве и доступны без сети.

Задачи хранятся только внутри этого приложения: iOS не переносит данные из Safari при установке ярлыка. Создайте аккаунт для синхронизации между устройствами или сделайте резервную копию через «Экспорт .json».

«Экспорт .json» сразу сохраняет файл в загрузки; «Поделиться» отдаёт его в любое приложение (AirDrop, Почта, «Файлы», Telegram). Импорт объединяет задачи, ничего не затирая.

Установить на iPhone Safari → «Поделиться» → «На экран “Домой”» — приложение откроется без адресной строки.

Аккаунт

Задачи можно вести без аккаунта — они останутся только на этом устройстве. Аккаунт добавляет синхронизацию между вашими устройствами.

Вход

Пароль хранится на сервере в виде scrypt-хэша. Данные аккаунта — ваши личные: другой пользователь их не видит.

Сервер синхронизации

По умолчанию аккаунты работают на том же адресе, с которого открыто приложение. Если сайт лежит на статическом хостинге (GitHub Pages, Netlify), а server.js запущен отдельно — укажите его адрес.

На сервере должен быть разрешён origin этого сайта: ALLOWED_ORIGINS=https://user.github.io node server.js. Проверить сервер можно, открыв /api/health в браузере.

синхронизировано

Выход не удаляет задачи: они остаются на устройстве в локальном режиме, а при следующем входе синхронизация продолжится с того же места.

Установить PIN

PIN блокирует приложение на этом устройстве и хранится только здесь (PBKDF2-SHA256, 120 000 итераций). Восстановить PIN нельзя — он не связан с паролем аккаунта.
