РУЧНОЙ ПУШ В GIT — ИНСТРУКЦИЯ
================================

Архив содержит рабочую копию репозитория Edsonssss/pwa (ветка main)
БЕЗ каталога .git. Коммит с исправлениями: 6c615f2.

ВАРИАНТ А — поверх существующего клона (сохраняет историю)
-----------------------------------------------------------
1. Склонируйте репозиторий (если ещё нет):
       git clone https://github.com/Edsonssss/pwa.git
       cd pwa
       git checkout main
2. Распакуйте архив ПОВЕРХ этой папки (с заменой файлов):
       unzip -o pwa-manual-push.zip -d .
   (Windows: извлечь через проводник с заменой; macOS: ditto -x -k pwa-manual-push.zip .)
3. Закоммитьте и запушьте:
       git add -A
       git commit -m "iOS-аудит: исправления P0/P1/P2"
       git push origin main

ВАРИАНТ Б — через git-bundle (история коммита 6c615f2 как есть)
---------------------------------------------------------------
Рядом лежит pwa-main.bundle — это полный дамп ветки main вместе с историей.
В существующем клоне:
       git fetch /путь/к/pwa-main.bundle main:main
       git push origin main
Или с нуля:
       git clone pwa-main.bundle pwa
       cd pwa
       git remote set-url origin https://github.com/Edsonssss/pwa.git
       git push origin main

ВАРИАНТ В — просто залить файлы через веб GitHub
-------------------------------------------------
1. Откройте https://github.com/Edsonssss/pwa/upload/main
2. Перетащите файлы из архива (папки icons/ и tools/ загружайте целиком).
   История при этом не сохранится — коммит создастся веб-интерфейсом.

-------------------
